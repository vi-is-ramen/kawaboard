# kawaboard ♡

Кавайная доска для рисования + набор x86-инструментов: дизассемблер, ассемблер
и конвертер систем счисления. Работает как десктопное приложение
(Eel + браузерное окно), собирается в единый исполняемый файл и ставится
через `.deb` / `.pkg.tar.zst` / net-установщик для Windows.

> Рисуй, пиши текст, ковыряй байтики — всё в одном окне.

---

## Возможности

### Доска
- Кисть с **поддержкой силы нажатия пера** (графические планшеты), толщина и
  цвет настраиваются
- Бесконечная вниз доска: кнопка «ещё местечко~» внизу
- Сохранение/загрузка доски в файл `*.kawadesk` через нативные диалоги ОС &mdash;
  **вместе с историей undo**

### Утилиты
- HEX &rarr; ассемблер (Capstone, 16/32/64-bit)
- ассемблер &rarr; HEX (Keystone, 16/32/64-bit)
- конвертер чисел: Dec / Hex / Bin / Oct

## Требования

- Python **3.14+** (менеджируется через uv)
- [uv](https://docs.astral.sh/uv/)
- [just](https://just.systems/) &mdash; для удобных команд
- Браузер для UI: Chrome / Edge / Chromium

## Установка

### Windows (netinst)

Одна строка &mdash; скачает свежий релиз с GitHub и откроет GUI-установщик
(PowerShell):

```sh
powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr https://raw.githubusercontent.com/vi-is-ramen/kawaboard/main/installer/kawaboard-netinst.ps1 -UseBasicParsing | iex"
```

Ставит в `%LOCALAPPDATA%\kawaboard`, создаёт ярлыки и запись
в «Установке и удалении программ». Админка не нужна.

### Debian / Ubuntu

```sh
sudo apt install ./kawaboard_X.Y.Z_amd64.deb
```

### Arch Linux

```sh
sudo pacman -U kawaboard-X.Y.Z-x86_64.pkg.tar.zst
```

## Формат `.kawadesk`

Доска сохраняется как JSON:

```json
{
  "format": "kawadesk",
  "version": 1,
  "savedAt": "2026-01-01T00:00:00Z",
  "objects": [ ],
  "extraHeight": 400,
  "penColor": "#FFB6C1",
  "penSize": 3,
  "history": [ { "json": "...", "h": 600 } ]
}
```

В `history` лежит полная история изменений, поэтому после открытия файла
кнопка «отменить» работает так, будто доску и не закрывали.

## Управление

| Действие                        | Как                                          |
|---------------------------------|----------------------------------------------|
| Кисть / ластик / курсор / текст | кнопки на панели инструментов                |
| Свой цвет                       | клик по иконке палитры                       |
| Удалить выделенное              | `Delete` / `Backspace`                       |
| Снять выделение / отмена        | `Esc`                                        |
| Подтвердить текст               | `Enter` или клик вне поля                    |
| Редактировать текст             | двойной клик по тексту инструментом «курсор» |
| Расширить доску вниз            | кнопка «ещё местечко~» под доской            |
